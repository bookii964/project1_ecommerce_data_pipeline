     ingest_run_id 가 의미를 가질 수 있기 때문이다.

[원본 값 보존]
------------------------------------------------------------------------------------
  타임스탬프 6만 건을 NULL 처리했으므로 원본을 timestamp_raw 에 남겼다.

  SQL 예시 — NULL 처리된 이벤트의 원본값 확인:
    SELECT time_flag, timestamp_raw, COUNT(*)
    FROM   clickstream
    WHERE  event_time IS NULL
    GROUP  BY 1, 2
    ORDER  BY 3 DESC;
